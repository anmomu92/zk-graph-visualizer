This is a graph visualizer that works along zk-org.

## Dependencies

- [zk-org](https://github.com/zk-org/zk)

## Features

- Search bar.
- Hidable note information panel.
- Movable nodes.

## Navigation

- When searching your note in the search bar, press `Enter` to jump to the next match, or `Shift + Enter` to jump to the previous one.
- Click anywhere outside the graph to hide the note information panel

## Installation

Just clone this repository...

```bash
git clone https://github.com/anmomu92/zk-graph-viz.git
```

...and, within the cloned repository, run the install script:

```bash
cd zk-graph-viz
./install.sh
```
